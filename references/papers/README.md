# Papers

Store source PDFs here when licensing and repository policy allow it.

Suggested filename format:

```text
author-year-short-title.pdf
```

Examples:

```text
assran-2023-jepa.pdf
stewart-2022-torchgeo.pdf
vl-jepa-2026.html
```

For standards or papers not stored locally, keep the citation in `../citations.bib`
and add a note in `../notes/` describing why the source matters.
